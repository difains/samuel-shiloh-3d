# 실로 성막과 어린 사무엘 3D (Ancient Shiloh & Young Samuel 3D)

개역개정 성경(사무엘상 1장~4장, 사사기 21장)의 역사적·성경적 고증을 기반으로 제작된 인터랙티브 3D 성경 세계입니다.
Meng To's Seijaku 및 Dream-Loop 아트 디렉션을 적용한 Three.js WebGL 고품질 가상 환경으로 구현되었습니다.

## 🌟 주요 특징

- **어린 사무엘 아바타**: 세마포 에봇과 작은 겉옷, 손에 든 올리브 기름 등불, `[G]` 기도 무릎 꿇기 및 성령의 임재 오라.
- **성경 랜드마크 6종**:
  1. 실로 성막 본전 (언약궤와 꺼지지 않은 하나님의 등불 앞)
  2. 대제사장 엘리의 처소
  3. 한나의 서원 기도 터 (성막 문설주)
  4. 성막 뜰 놋 번제단과 물두멍
  5. 실로 성문과 망루
  6. 실로 북쪽 올리브 과원과 포도원
- **미니맵 인터랙티브 순간이동 (Fast-Travel)**: 레이더 미니맵 클릭 또는 1~6 단축키를 통해 성경 속 주요 장소로 즉시 워프.
- **개역개정 성경 본문 대화**: 각 장소에서 `[E]` 상호작용 시 성경 구절과 등장인물 대화 및 영적 묵상 제공.
- **실시간 PBR 및 포스트 프로세싱**: `UnrealBloomPass` 글로우, `ACESFilmicToneMapping`, `PMREMGenerator` 환경 반사.
- **고대 수금(Kinnor) 사운드스케이프**: Web Audio API로 실시간 합성되는 히브리 고대 선율.

## 🕹️ 조작법

- `W`, `A`, `S`, `D`: 이동
- `Shift`: 전력 질주 (Sprint)
- `Space`: 점프
- `마우스 좌클릭`: 시점 360도 회전
- `V`: 1인칭 / 3인칭 시점 전환
- `C`: 시네마틱 자동 순환 투어
- `G`: 기도 모드 ("말씀하옵소서 주의 종이 듣겠나이다")
- `T`: 시간대 전환 (거룩한 성막의 밤 → 여명의 아침 → 찬란한 한낮)
- `1` ~ `6`: 성경 랜드마크 즉시 순간이동
- `E`: 성경 대화 & 묵상 열기
- `M`: 배경음악 음소거 토글
